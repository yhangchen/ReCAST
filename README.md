# ReCAST

Official project page for **ReCAST: Reward Credit Assignment across Timesteps
for Online Diffusion Reinforcement**.

- [Paper](https://arxiv.org/abs/2609.13425)
- [Project page](https://yhangchen.github.io/ReCAST/)
- Code: coming soon

## Local preview

The site is plain HTML, CSS, and JavaScript with no build step. Serve it locally
so the interactive gallery can load:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
